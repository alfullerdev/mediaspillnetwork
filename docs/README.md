# Media Spill Network

React site for Media Spill Network, redesigned around its existing artist discovery, production, and creative-services content.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Netlify

The included `netlify.toml` is configured for Netlify:

- Build command: `npm run build`
- Publish directory: `dist/client`

Connect this folder or its Git repository in Netlify and deploy. The contact form currently provides a polished on-page confirmation; connect it to your preferred email or form provider when ready to receive submissions.
